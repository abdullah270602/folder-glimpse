# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Until GitHub private vulnerability reporting is enabled for this repository, contact the
maintainer at **abdullahnaseem27@gmail.com** with:

- a concise description of the issue;
- affected versions or commits;
- reproducible steps or a proof of concept;
- the likely impact; and
- any suggested mitigation.

Do not include unrelated personal data, credentials, or secrets. You should receive an
acknowledgement within seven days. Please allow reasonable time for investigation and a
coordinated fix before public disclosure.

## Supported versions

FolderGlimpse is currently pre-stable. Security fixes target the latest published release
and the current default branch; older builds are not maintained separately.
